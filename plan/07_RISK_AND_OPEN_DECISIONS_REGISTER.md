### 2.1 Resolution of the `DEC-13` / `Gate Auth-1` Circular Dependency (`Critical Correction D`)
In `R2.1.1`, `DEC-13` blocked `Gate Auth-1` (the entry gate to `M00`) while simultaneously listing *"Benchmark proving $< 5\text{ ms}$ verification latency per pattern piece across all 63 reference contours (`AC-03`)"* as the evidence required to finalize `DEC-13`. Because the 63 reference contours (`M00.3`) and the oracle benchmark harness (`M00.4`) are created *during* `M00`, requiring `M00.4` benchmark outputs before `Gate Auth-1` created a circular dependency.

`R2.1.2` resolves this circular dependency explicitly without weakening governance authority or unlocking `M00`:

1. **Primary Governance Path (`Option B` — Two-Stage Split of `DEC-13` Across `Gate Auth-1` and `Gate Auth-2`):**
   - **`DEC-13 Stage 1` (At `Gate Auth-1` — Initial Oracle Library Selection for `M00.4`):**
     - **Scope:** Authorizes using Python `fractions.Fraction` (exact rational arithmetic) + `mpmath.iv` (`mp.dps = 80`) + exact rational/Bernstein polynomial matrices as the candidate reference-oracle stack for `M00.4` (`services/fashion-engine/tests/oracles/`).
     - **Evidence Required at `Gate Auth-1` (Zero `M00` Execution Required):** Static architectural and mathematical specification review of `ADR-009` (`R2.1.2`) and documented `mpmath.iv` / `fractions.Fraction` capabilities. Because `M00.4` is an offline CI reference oracle rather than a real-time interactive CAD endpoint, sub-5ms runtime latency is not a prerequisite to begin building the offline oracle in `M00.4`.
     - **Approver:** Computational Geometry Lead & Project Owner sign-off at `Gate Auth-1`.
   - **`DEC-13 Stage 2` (At `Gate Auth-2` — Library Qualification & `< 5 ms` Runtime Performance Confirmation for `M02a` / `M02f`):**
     - **Scope:** Authorizes the production runtime verification library configuration for `M02a` and `M02f` (`services/fashion-engine/app/pattern_engine/`), determining whether pure Python `mpmath.iv` + `NumPy`/`SciPy` Bernstein pre-screening meets the `< 5 ms` per-piece runtime budget or whether `python-flint` (C-ARB ball/interval arithmetic) acceleration is enabled for `M02`.
     - **Evidence Required at `Gate Auth-2` (Produced During `M00.4` / `M00.10` After `Gate Auth-1` Approval):**
       1. Completed **`IntervalLibraryQualificationReport` (`ADR-009 §3.4`)** qualifying every relied-upon `mpmath.iv` operation against exact `fractions.Fraction` bounds, and
       2. Empirical latency & enclosure benchmark across all 63 reference contours (`Class A` and `Class B` fixtures extracted in `M00.3`/`M00.4`) proving `< 5 ms` verification latency per pattern piece (`AC-03`).
     - **Approver:** Computational Geometry Lead & Principal Architect sign-off at `Gate Auth-2`.

2. **Optional Pre-`M00` Non-Production Technology Spike (`Option A` — `SPIKE-DEC13-01`, Available If Requested by Owner Before `Gate Auth-1`):**
   If the Project Owner or Computational Geometry Lead desires empirical micro-benchmark numbers *before* signing `DEC-13 Stage 1` at `Gate Auth-1`, a strictly bounded, non-production research spike (`SPIKE-DEC13-01`) may be separately authorized:
   - **Scope:** Standalone, throwaway script executed outside `/app/applet/src/` (in an isolated `/tmp/spike-dec13/` scratch directory) evaluating `mpmath.iv`, `fractions.Fraction`, and `python-flint` on 5 synthetic mathematical test curves.
   - **Inputs:** 5 closed-form analytical curves (CCW circle of radius $R=10\text{ cm}$, straight segment, inflection cubic, interior stationary cusp at $t=0.25$, over-offset concave cubic).
   - **Outputs:** Stand-alone markdown/JSON timing and interval-enclosure comparison table presented for `DEC-13 Stage 1` review.
   - **Owner Approval:** Requires explicit Project Owner permission to run; does **not** authorize `M00`.
   - **Exit Criteria:** Verification of outward interval containment against exact `fractions.Fraction` values and timing comparison on the 5 synthetic curves, followed by immediate deletion of `/tmp/spike-dec13/`.
   - **Explicit Prohibition on Production Adoption:** Zero code from `SPIKE-DEC13-01` may be committed to the repository, imported into `services/fashion-engine`, or treated as `M00.4` or `M02` deliverables.
