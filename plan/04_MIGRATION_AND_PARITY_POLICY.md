### 2.4 Five-Dimensional Qualification of Oracle Independence (`Critical Correction F`, `ADR-009 §6`)

2. **Source-Code Independence (`Mandatory for M00 & M02`):** Zero shared calculation functions or imports between `services/fashion-engine/tests/oracles/` and `services/fashion-engine/app/pattern_engine/` (`AC-04`).
3. **Arithmetic & Library Independence (`Rational Cross-Check Mandatory for M00; Dual-Library Desirable for M02/M10`):**
   - **Shared Dependency Disclosure:** Whenever both the `M00.4` oracle and `M02` runtime certification call `mpmath.iv` (`MPI` interval arithmetic), they share the `mpmath` library dependency.
   - **Mandatory Mitigation in `M00.4`:** All polynomial coefficients ($Q(t)$, $C(t)$, $P_{\mathrm{exact}}(t)$, $P_{\mathrm{margin}}(t)$), Green's theorem area (`Method C2`), Sturm root isolation, and the 8-point **`IntervalLibraryQualificationReport` (`ADR-009 §3.4`)** are evaluated or cross-checked in **exact rational arithmetic (`fractions.Fraction`)**, which is arithmetically independent of `mpmath.iv`.
   - **Desirable Future Enhancement (`DEC-13 Stage 2` / `M10`):** Cross-checking `mpmath.iv` against a secondary C-library interval backend (`python-flint` / `Arb` ball arithmetic).
4. **Input & Fixture Independence (`Mandatory for M00 & M02`):** Class B normative fixtures are constructed from analytical closed-form geometry (circles, straight lines, known rational cusps) and oracle evaluation prior to `M02` implementation.
5. **Reviewer & Verification Independence (`Mandatory for All Gates Auth-1–Auth-6`):** Gate review and acceptance sign-off are conducted independently of the authoring workflow.

## 3. Five-Concept Numerical Assurance, Parameter-to-Output Propagation, Four-Layer `Method C1-Cert` & Corrected Six-Category Offset Taxonomy (`ADR-009`)

### 3.1 Explicit Triangle Inequality, Five-Concept Separation & Parameter-to-Output Error Bound (`Critical Correction B`)
For any exact mathematical output value $X_{\mathrm{exact}}$, production `float64` output $X_{\mathrm{float64}}$, and independent reference output $X_{\mathrm{ref}}$, the output error obeys the triangle inequality:

$$|X_{\mathrm{float64}} - X_{\mathrm{exact}}| \;\le\; \underbrace{|X_{\mathrm{float64}} - X_{\mathrm{ref}}|}_{E_{\mathrm{obs}}(X)} \;+\; \underbrace{|X_{\mathrm{ref}} - X_{\mathrm{exact}}|}_{\le \, B_{\mathrm{ref}}(X)}$$

1. **Five Concepts (`ADR-009 §2.2`):** **(1) $X_{\mathrm{ref}}$** (High-Precision Reference Result), **(2) $E_{\mathrm{obs}}(X)$** (Observed Implementation-to-Reference Discrepancy), **(3) $B_{\mathrm{ref}}(X)$** (Validated Reference-to-Exact Output Enclosure), **(4) $B_{\mathrm{cert}}(X)$** (Validated Implementation-to-Exact Output Error Bound), and **(5) $\tau_{\mathrm{domain}}(X)$** (Engineering Acceptance Tolerance).
2. **Parameter Uncertainty Is Not Geometric Output Error (`Critical Correction B`, `ADR-009 §2.3`):**
   - For any root-dependent geometric output $X(t^*)$ where $t^* \in I_t = [\underline{t}, \overline{t}]$, the parameter bracket half-width $r_{\mathrm{param}}(I_t) = \frac{1}{2}(\overline{t} - \underline{t})$ bounds only $|t^* - t_{\mathrm{mid}}|$ and **must never be reported as $B_{\mathrm{ref}}(X)$**.
   - A valid geometric output error bound $B_{\mathrm{ref}}(X) \ge |X(t^*) - X_{\mathrm{ref}}|$ requires either:
     - **Validated Derivative Propagation (`Method B1`):** $|X(t^*) - X(t_{\mathrm{mid}})| \le \bigl(\sup_{t \in I_t} |X'(t)|\bigr)\frac{\overline{t} - \underline{t}}{2}$ where $\sup_{t \in I_t}|X'(t)|$ is itself enclosed over $I_t$ in qualified interval arithmetic (plus point-evaluation enclosure $\delta_{\mathrm{eval}}$ of $X(t_{\mathrm{mid}})$), or
     - **Direct Output Interval Enclosure (`Method B2`):** $X(t^*) \in X(I_t) = [\underline{X}(I_t), \overline{X}(I_t)]$ with $B_{\mathrm{ref}}(X) = \frac{1}{2}\bigl(\overline{X}(I_t) - \underline{X}(I_t)\bigr)$.

### 3.2 Four-Layer `Method C1-Cert` Assurance & `mpmath.iv` Library Qualification (`Critical Correction C`)
- **`Method C1-Est` (`CONSERVATIVE_ENGINEERING_ESTIMATE`):** The $S_{\mathrm{safety}} = 16.0$ adaptive Gauss–Legendre discrepancy formula is strictly an empirical engineering estimate (`ADR-009 §3.1`), never a certified bound.
- **`Method C1-Cert` (`ADR-009 §3.2` — Four Separate Assurance Layers):**
  1. **Layer 1 (Mathematical Theorem):** On any Bézier segment $\mathbf{B}_k$, the **non-strict** inequality $L_{\mathrm{chord}}(\mathbf{B}_k) \le L_{\mathrm{exact}}(\mathbf{B}_k) \le L_{\mathrm{control\ polygon}}(\mathbf{B}_k)$ holds by the triangle and Minkowski integral inequalities (with equality on collinear monotonically ordered control polygons).
  2. **Layer 2 (Algorithmic Derivation):** De Casteljau subdivision monotonically refines the lower and upper bounds at rate $\mathcal{O}(h^2)$ on smooth segments and $\mathcal{O}(h)$ at cusps.
  3. **Layer 3 (Implementation Assurance Obligations & `Section 3.4` Library Qualification):** Requires lossless dyadic input intervals, outward-rounded interval enclosures for every subdivided control point, norm, and sum, upward rounding of $B_{\mathrm{cert}}(L) = \max(L_{\mathrm{fp64}} \ominus_{\uparrow} \underline{L}_{\mathrm{chord}}, \overline{L}_{\mathrm{poly}} \ominus_{\uparrow} L_{\mathrm{fp64}})$, and a passed **`IntervalLibraryQualificationReport`** verifying the whitelisted `mpmath.iv` operations (`+`, `-`, `*`, `/`, `iv.sqrt`) against exact `fractions.Fraction` enclosures.
  4. **Layer 4 (Empirical Verification):** Necessary bug-detection tests, never treated as a substitute for Layers 1–3.

### 3.3 Corrected Offset Derivative (`1 - s d kappa`), Six-Category Taxonomy & Tri-State Outcomes (`Critical Correction A`)
- **Corrected Offset Derivative Identity (`ADR-009 §4.1`):**
  Under $\mathbf{O}(t) = \mathbf{B}(t) + s\,d\,\hat{\mathbf{n}}_+(t)$ ($d > 0$, $s \in \{-1, +1\}$) and $\hat{\mathbf{n}}_+'(t) = -\kappa(t)\,\mathbf{B}'(t)$ where $\kappa(t) = C(t)/Q(t)^{3/2}$, differentiating $\mathbf{O}(t)$ yields:
  $$\mathbf{O}'(t) \;=\; \bigl(1 - s\,d\,\kappa(t)\bigr)\,\mathbf{B}'(t) \;=\; \left(1 - \frac{s\,d\,C(t)}{Q(t)^{3/2}}\right)\mathbf{B}'(t), \qquad f(t) := 1 - \frac{s\,d\,C(t)}{Q(t)^{3/2}}.$$
- **Separate Treatment of Zero-Speed Base Points ($Q(t) = 0$) & Corrected Sign Condition ($s\,d\,C(t) > 0$):**
  1. Zero-speed base points $Q(t^*) = x'(t^*)^2 + y'(t^*)^2 = 0$ are isolated **first and separately** (`Category 2a`) before applying any formula dividing by $Q(t)^{3/2}$.
  2. On sub-intervals with certified $\underline{Q([a,b])} > 0$, concave/evolute-side offsetting occurs when $S(t) := s\,d\,C(t) > 0$:
     - **`REGULARITY_MARGIN_VIOLATION` (`Category 1`):** $0 < f(t) < \varepsilon_{\mathrm{margin}} \iff s\,d\,C(t) > 0 \wedge P_{\mathrm{exact}}(t) > 0 \wedge P_{\mathrm{margin}}(t) < 0$.
     - **`ACTUAL_ZERO_SPEED_CUSP` (`Category 2`):** $Q(t^*) = 0$ (`2a`), or $Q(t^*) > 0 \wedge s\,d\,C(t^*) > 0 \wedge P_{\mathrm{exact}}(t^*) = Q(t^*)^3 - d^2 C(t^*)^2 = 0$ (`2b`).
     - **`TANGENT_REVERSAL` (`Category 3`):** $Q(t) > 0 \wedge f(t) < 0 \iff s\,d\,C(t) > Q(t)^{3/2} \iff s\,d\,C(t) > 0 \wedge P_{\mathrm{exact}}(t) < 0$ (or $\tilde{\mathbf{O}}'(u)\cdot\mathbf{B}'(t(u)) < 0$).
     - **`LOCAL_OFFSET_SELF_INTERSECTION` (`Category 4`)**, **`GLOBAL_CONTOUR_SELF_INTERSECTION` (`Category 5`)**, and **`INCONCLUSIVE_VERIFICATION` (`Category 6`)**.
