## 2. Summary of Targeted Corrections in Blueprint Revision 2.1.1 (`12_BLUEPRINT_R2_1_TO_R2_1_1_CHANGELOG.md`)

1. **Correction A — Reference Oracle & Triangle-Inequality Error Enclosure (`ADR-009`, `04`, `06`, `M00`, `M02`):** Enforces the full triangle inequality $\|X_{\mathrm{float64}} - X_{\mathrm{exact}}\| \le \|X_{\mathrm{float64}} - X_{\mathrm{ref}}\| + \|X_{\mathrm{ref}} - X_{\mathrm{exact}}\| = E_{\mathrm{obs}} + B_{\mathrm{ref}} \le B_{\mathrm{cert}} \le \tau_{\mathrm{domain}}$. Never assumes $\|X_{\mathrm{ref}} - X_{\mathrm{exact}}\| = 0$. Establishes the **5-Concept Numerical Assurance Taxonomy** ($X_{\mathrm{ref}}$, $E_{\mathrm{obs}}$, $B_{\mathrm{ref}}$, $B_{\mathrm{cert}}$, $\tau_{\mathrm{domain}}$) and the `NumericalVerificationRecord` schema.
2. **Correction B — Downgrade of `Method C1` Quadrature-Difference Formula (`Method C1-Est`) vs. Certified Enclosure (`Method C1-Cert`):** Downgrades the adaptive Gauss–Legendre quadrature discrepancy formula $E_{\mathrm{est}} = S_{\mathrm{safety}}\cdot\|I_{\mathrm{GL}(n)} - I_{\mathrm{GL}(2n)}\|$ ($S_{\mathrm{safety}}=16.0$, `Method C1-Est`) to a **`CONSERVATIVE_ENGINEERING_ESTIMATE`** (`EMPIRICAL_ESTIMATE`), prohibiting any `certified` or `proof` label for it. Separates it from **`Method C1-Cert`** (De Casteljau chord vs. control-polygon convex-hull interval enclosure $\underline{L}_{\mathrm{chord}} \le L_{\mathrm{exact}} \le \overline{L}_{\mathrm{poly}}$ in `mpmath.iv`, backed by Minkowski's integral inequality on the Bernstein derivative basis).
3. **Correction C — Six-Category Offset Geometry Failure Taxonomy & Sign Convention (`ADR-009`, `M02`, `M05`):** Independently defines **(1) `REGULARITY_MARGIN_VIOLATION`** ($0 < 1 + s\,d\,\kappa(t) < \varepsilon_{\mathrm{margin}}$), **(2) `ACTUAL_ZERO_SPEED_CUSP`** ($1 + s\,d\,\kappa(t^*) = 0$), **(3) `TANGENT_REVERSAL`** ($1 + s\,d\,\kappa(t) < 0$), **(4) `LOCAL_OFFSET_SELF_INTERSECTION`**, **(5) `GLOBAL_CONTOUR_SELF_INTERSECTION`**, and **(6) `INCONCLUSIVE_VERIFICATION`**, with explicit `CARTESIAN_RH_CCW` sign conventions.
4. **Correction D — Tri-State Interval Verification (`CERTIFIED_VALID`, `CERTIFIED_INVALID`, `INCONCLUSIVE`):** Fixes the depth-20 subdivision fallback so a lower bound below threshold ($\underline{F} \le 0 < \overline{F}$) is classified as **`INCONCLUSIVE`**, never misreported as a confirmed cusp, tangent reversal, or self-intersection. `INCONCLUSIVE` fails closed at release gates (`is_production_ready = False`) and triggers a 4-step precision/degree/subdivision escalation ladder.
5. **Correction E — Strict Separation of `M00` (Migration Prep & Independent Oracles) vs. `M02` (Authoritative Production Implementation):** Restricts **`M00` (`M00.1`–`M00.10`)** strictly to inventory, defect reproduction, legacy TS freeze, Class A/B fixtures, and the independent reference-oracle harness (`M00.4` in `services/fashion-engine/tests/oracles/`). Assigns all authoritative production geometry (`M02a`) and offset/trimming/validation (`M02f`) exclusively to **`M02` (`services/fashion-engine/app/pattern_engine/`)** with a 7-point oracle separation boundary.
6. **Correction F — Explicit Six-Gate Decision-to-Gate Authorization Matrix (`07`, `05`, `06`, `10`):** Maps every `DEC-01`–`DEC-13` and `ADR-001`–`ADR-009` across **`Gate Auth-1`** (`M00` commencement — currently `BLOCKED / UNAUTHORIZED`), **`Gate Auth-2`** (`M01`/`M02` build entry), **`Gate Auth-3`** (`Vertical Slice`), **`Gate Auth-4`** (`Release Level A` pilot entry), **`Gate Auth-5`** (`Release Level B` pilot exit), and **`Gate Auth-6`** (`Release Level C` enterprise scale).
7. **Correction G — Cross-Document Consistency & Changelog (`12_BLUEPRINT_R2_1_TO_R2_1_1_CHANGELOG.md`):** Reconciles all mathematical, offset, boundary, and gate definitions across `plan/` while preserving `11_BLUEPRINT_R2_TO_R2_1_CHANGELOG.md` unchanged.
